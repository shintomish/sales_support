### 追加検証: Prompt Caching 効果 (2026-05-21)

**Anthropic Prompt Caching** (`cache_control: ephemeral`) を有効にして再計測:

| 試行 | input | cache_write | cache_read | output |
|---|---|---|---|---|
| 1回目 (write) | 1,722 | 1,842 | 0 | 954 |
| 2回目 (read) | 1,361 | 0 | 1,842 | 1,710 |

- システム prompt + 要件 (1,842 tokens) を **同一 PMS 内の全 EMS 判定で共有**
- 5min ephemeral cache のため、提案 1 件のフローで完結すれば書込料金は 1 回のみ

**コスト試算 (5 候補/案件)**:

| 区分 | 計算 | コスト |
|---|---|---|
| Stage 1 | 1,377 × $3/M + 881 × $15/M | $0.017 |
| Stage 2 #1 (cache write) | 1,722×$3/M + 1,842×$3.75/M + 954×$15/M | $0.026 |
| Stage 2 #2-#5 (cache read) | 4 × (1,500×$3/M + 1,842×$0.30/M + 1,100×$15/M) | $0.080 |
| **合計** | | **約 $0.123 / 案件** |

→ **月 360 件で約 $44** (cache 無し試算 $50 から 12% 削減)。出力 token を絞れば $30/月台も視野。

### 追加検証: Haiku 4.5 (NG)

参考までに Stage 2 を `claude-haiku-4-5` で実行 (コスト 1/3)。結果:
- Angular.js (1.x) vs Angular (2+) の **バージョン違いを検出できず ◯ 判定** (営業ミスを誘発)
- 「小規模チームリーダー」=「テックリード経験」と短絡 ◯
- 商流要件で「要確認 △」が ◯ に格下げ

→ **本実装は Sonnet 4.6 で固定**。コスト削減は prompt cache + 出力トリムで対応する。
