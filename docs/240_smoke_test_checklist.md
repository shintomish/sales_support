## 2. 共通チェック（全画面で）

各画面を開いた直後に以下を確認：

- [ ] 画面が表示される（白画面・エラー画面でない）
- [ ] ブラウザ Console にエラーが出ていない（F12 → Console）
- [ ] Network タブで 4xx / 5xx が出ていない（F12 → Network）
- [ ] 日本語が正しく表示される（文字化けなし）
- [ ] レイアウトが崩れていない（はみ出し・要素重なりなし）
